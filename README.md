# Vehicle Damage Classification

A computer vision project that explores how vehicle photos can support the initial triage of auto insurance claims. The classification task is framed around helping a reviewer sort incoming images and decide which cases to inspect next.

## Explore the project

Open [Vehicle Damage Classification.ipynb](Vehicle%20Damage%20Classification.ipynb) in GitHub's notebook viewer or download it to inspect the analysis locally. To rerun the notebook, first check its data-loading cells for image inputs and paths and prepare the Python environment it expects.

The project is a prototype for claims triage. Decisions about coverage, repair costs, and claim approval remain separate from image classification.
